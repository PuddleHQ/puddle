# 12. Glossary

The product terms used in the code, the UI and these pages, with what each one means in Puddle.
Where the UI uses a different word from the code, both are given; the **Defined in** column names
the type, module or file a reader can check.

## Workspaces and VMs

| Term                            | Meaning                                                                                                                                                                           | Defined in                                                                                                                 |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Workspace**                   | One development environment: a sandbox, its disk volume, its repositories, settings and rules. The unit the user creates, starts, stops and deletes.                              | `WorkspaceId` in `crates/puddle-types/src/name.rs`                                                                         |
| **Workspace id** and **name**   | The id is a DNS label that never changes and keys everything (rules, volume, sandbox, the editor's host name). The name is free display text that keys nothing.                   | `WorkspaceId` in `crates/puddle-types/src/name.rs`; `DisplayName` in `crates/puddle-services/src/workspaces.rs`            |
| **Sandbox**                     | The microVM that runs a workspace, named after the workspace id. The UI never says sandbox; it says workspace.                                                                    | `SandboxName` in `crates/puddle-types/src/name.rs`; `Sandbox` trait in `crates/puddle-compute/src/runtime.rs`              |
| **Workspace status**            | The sandbox's state: created, starting, running, draining (UI: "Stopping"), paused, stopped, crashed, volume missing.                                                             | `crates/puddle-types/src/event.rs`; labels in `ui/src/lib/workspaces/model.ts`                                             |
| **Volume** (UI: "Disk")         | The named disk `ws-<id>`, mounted at `/workspace`, that holds the workspace's work. It outlives every sandbox made for it; deleting it is a separate, checked act.                | `VolumeName` in `crates/puddle-types/src/name.rs`; `crates/puddle-workspace`; [ADR 0006](../adr/0006-workspace-storage.md) |
| **Root disk**                   | The sandbox's own system disk, outside the volume. It can be reset (losing what was installed there) or grown, never shrunk.                                                      | `GrowRootDiskRequest` in `crates/puddle-services/src/wire/workspaces.rs`                                                   |
| **Orphan volume**               | A workspace disk Puddle still has but that is not in its workspace list. The UI offers to restore it as a workspace.                                                              | `crates/puddle-services/src/wire/orphans.rs`; `ui/src/lib/components/OrphanVolumesNotice.svelte`                           |
| **Reclaim**                     | Handing disk space the workspace no longer uses back to the host (trim).                                                                                                          | `crates/puddle-workspace`; "Reclaiming space" in `ui/src/lib/workspaces/model.ts`                                          |
| **Repository** and **checkout** | A repository Puddle manages for a workspace (an entry id and a clone URL), cloned into a checkout folder directly under the volume root.                                          | `crates/puddle-services/src/workspaces/repositories.rs`; `CheckoutDir` in `crates/puddle-types/src/name.rs`                |
| **Start folder**                | The folder under the volume where terminals and the editor open.                                                                                                                  | `crates/puddle-services/src/workspaces.rs`; `ui/src/lib/components/StartFolderSetting.svelte`                              |
| **Image**                       | The devcontainer image a workspace boots. Puddle has no base image of its own.                                                                                                    | `ImageRef` in `crates/puddle-types/src/name.rs`; [ADR 0005](../adr/0005-no-base-image.md)                                  |
| **Session user**                | The guest user that terminals, the editor and clones run as: `agent` (a plain user with passwordless sudo, the default) or `root`.                                                | `SessionUser` in `crates/puddle-types/src/session_user.rs`; [ADR 0008](../adr/0008-non-root-session-user.md)               |
| **Boot hook**                   | `guest/boot.sh`, run as root after every create and start, that sets up the guest: proxy settings, trust roots, the session user, guest files.                                    | `crates/puddle-boot/guest/boot.sh`, `crates/puddle-boot/src/hook.rs`                                                       |
| **Readiness gate**              | Per-sandbox state (down, booting, ready, failed). No SSH or exec is served until the boot hook has succeeded.                                                                     | `Gate`, `GateState` in `crates/puddle-boot/src/gate.rs`                                                                    |
| **Guest file**, **guest env**   | Files and environment variables the boot hook writes into the guest.                                                                                                              | `crates/puddle-types/src/guest.rs`                                                                                         |
| **Merged file**                 | A guest file where Puddle owns only some keys and edits them in place (Docker's `config.json`, VS Code's machine settings).                                                       | `crates/puddle-types/src/merge.rs`                                                                                         |
| **Shell init**                  | A per-workspace script that login shells in the guest source. The host's copy is the source of truth, so the workspace cannot change it for good.                                 | `crates/puddle-store/src/shell_init.rs`                                                                                    |
| **Guest agent**                 | The static binary inside each sandbox that carries the guest's connections, name lookups, editor traffic, port forwards and reports to the host over vsock.                       | `crates/puddle-agent`                                                                                                      |
| **Control stream**              | The agent's stream for guest-to-host events, one of the multiplexed (yamux) streams on the workspace's vsock route.                                                               | `crates/puddle-agent-proto/src/lib.rs`                                                                                     |
| **Route**                       | The per-workspace host endpoint (named pipe or Unix socket) the agent connects on. The proxy learns which workspace a connection belongs to from the route, never from the guest. | `crates/puddle-ipc`; `crates/puddle-proxy/src/lib.rs`                                                                      |
| **Terminal**                    | A shell in the workspace opened from a Puddle screen.                                                                                                                             | `TerminalLink` in `crates/puddle-services/src/terminals.rs`                                                                |
| **Runtime**, **msb**            | The microVM runtime behind the `Runtime` trait. In the product always the msb runtime bundled with Puddle, checked for its exact version and hashes.                              | `Runtime` in `crates/puddle-compute/src/runtime.rs`; `BundledRuntime` in `crates/puddle-runtime`                           |
| **Lifecycle**                   | Puddle's VMs live and die with Puddle: they are stopped when it quits, a kill-on-close job covers them on Windows, and leftovers are cleaned up after a crash (reconcile).        | `crates/puddle-lifecycle`                                                                                                  |
| **Managed tools** (mise)        | Tool versions Puddle installs in a workspace with mise. Built, but off in the first release.                                                                                      | `MiseMode` in `crates/puddle-settings/src/workspace.rs`                                                                    |

## Network and rules

| Term                                             | Meaning                                                                                                                                                                                        | Defined in                                                                                                          |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **Egress proxy**                                 | Puddle's proxy, the only way out of a workspace. It decides each connection, resolves the name, checks the address, relays the bytes and records the outcome.                                  | `crates/puddle-proxy/src/proxy.rs`, `crates/puddle-proxy/src/lib.rs`                                                |
| **Request**                                      | What the rules decide on: workspace, host and port, with an optional protocol hint.                                                                                                            | `crates/puddle-types/src/policy.rs`; [rules spec](../spec/rules.md)                                                 |
| **Rule**                                         | Allow or deny for an exact host or a `.suffix`, globally or for one workspace, with an optional end time, a precedence and an on/off switch.                                                   | `crates/puddle-services/src/wire/rules.rs`; [rules spec](../spec/rules.md)                                          |
| **Effect**                                       | A rule's answer: allow or deny.                                                                                                                                                                | `crates/puddle-services/src/wire/rules.rs`                                                                          |
| **Scope**                                        | Where a rule applies: every workspace (global) or one workspace.                                                                                                                               | `crates/puddle-services/src/wire/rules.rs`                                                                          |
| **Exact** and **suffix**                         | The two pattern kinds: the identical host name, or every name under `.example.com`.                                                                                                            | `crates/puddle-types/src/policy.rs`                                                                                 |
| **Precedence**                                   | A number from 1 to 9 on every rule: of the rules that match, the highest precedence decides, even over a more specific rule. Built-in and System managed entries rank lowest.                  | `precedence` in `crates/puddle-services/src/wire/rules.rs`; [ADR 0007, one rule list](../adr/0007-one-rule-list.md) |
| **Expiry** (UI: "Ends")                          | When a rule stops matching. Checked when deciding; the sweeper then deletes the expired rule.                                                                                                  | `expires_at` in `crates/puddle-services/src/wire/rules.rs`                                                          |
| **Decision**                                     | The engine's answer to a request: allow, deny, pending or blocked.                                                                                                                             | `crates/puddle-types/src/policy.rs`                                                                                 |
| **Block reason**                                 | Why a request was refused outside the rules (a local address not switched on, UDP, an SSH host Puddle does not serve), each with its own audit code and the way out.                           | `crates/puddle-types/src/policy.rs`                                                                                 |
| **Pending request**                              | A request no rule matched. It is held and waits in the Inbox until the user decides; it never expires by age. States: requested, allowed, denied, expired.                                     | `crates/puddle-services/src/wire/rules.rs`; `crates/puddle-store/src/pending.rs`                                    |
| **Inbox**                                        | The screen of open pending requests, grouped by registrable domain, where the user allows or denies.                                                                                           | `InboxGroup` in `crates/puddle-services/src/wire/rules.rs`; `ui/src/routes/inbox`                                   |
| **Undo**                                         | Undoing a decision deletes the rule it made and lists the request in the Inbox again.                                                                                                          | `UndoOutcome` in `crates/puddle-services/src/wire/rules.rs`                                                         |
| **Actor**                                        | Who made a change: the command line, the UI, the API, or workspace creation (which allows the repository's own host).                                                                          | `crates/puddle-services/src/wire/rules.rs`                                                                          |
| **Rule set**                                     | A named bundle of entries switched on or off as one, globally or per workspace: built-in, the user's own, or System managed. The ADR and spec call it a "group"; the code and UI say rule set. | `RuleSetId` in `crates/puddle-types/src/policy.rs`; `crates/puddle-services/src/wire/rule_sets.rs`                  |
| **Built-in set**                                 | A read-only rule set that ships with Puddle, switched off until the user turns it on. Each set has one effect.                                                                                 | `BuiltInSet` in `crates/puddle-store/src/catalogue.rs`                                                              |
| **System managed**                               | Read-only allowed hosts that follow from the user's own setup (the editor server they chose, direct SSH), each with its reason.                                                                | `SystemReason` in `crates/puddle-services/src/wire/rule_sets.rs`; `ui/src/lib/components/SystemManagedList.svelte`  |
| **Method and path rule**                         | A rule that only refuses: a host, methods and a path pattern, checked on decrypted requests.                                                                                                   | `crates/puddle-services/src/wire/request_rules.rs`                                                                  |
| **Sweeper**                                      | The background task that deletes expired rules and old audit records, at start and every minute.                                                                                               | `crates/puddle-store/src/sweeper.rs`                                                                                |
| **Audit** (UI: "Activity")                       | The record of every connection and every change to rules, pending requests, rule sets and workspaces. The code and API say audit; the UI and `puddle audit` say activity log.                  | `crates/puddle-services/src/wire/audit_record.rs`, `crates/puddle-services/src/wire/audit.rs`                       |
| **Destination guard**                            | The check of each resolved address: its address class, the local-destination toggles and Puddle's own endpoints.                                                                               | `NetPolicy` in `crates/puddle-netpolicy/src/guard.rs`                                                               |
| **Address class**, **local category**            | Public (the rules alone decide) or local in one category: loopback, private, link-local, metadata, special, company network.                                                                   | `crates/puddle-netpolicy/src/classify.rs`; `LocalCategory` in `crates/puddle-types/src/local.rs`                    |
| **Local-destination toggle**                     | A per-category switch, global or per workspace, that lets rules allow local addresses. A toggle never allows anything on its own.                                                              | `LocalToggles` in `crates/puddle-settings/src/layer.rs`; `crates/puddle-netpolicy/src/access.rs`                    |
| **Company network**                              | Addresses treated as local because the host says they belong to the company network (a PAC `DIRECT`, a DNS suffix, a VPN route).                                                               | `CompanySignal` in `crates/puddle-types/src/local.rs`                                                               |
| **Puddle endpoints**                             | Puddle's own listeners (API, pull proxy, editor front, port forwards), which no workspace can reach.                                                                                           | `PuddleEndpoints` in `crates/puddle-netpolicy/src/endpoints.rs`                                                     |
| **Pull proxy** (UI: "Image downloads")           | The loopback proxy for Puddle's own image pulls: it applies the destination guard but no rules.                                                                                                | `crates/puddle-proxy/src/pull.rs`                                                                                   |
| **Stub DNS**                                     | The guest's name server, for tools that ignore proxy settings. The rules decide the name first; a name that is not allowed is never looked up.                                                 | `crates/puddle-agent-proto/src/lib.rs`, `crates/puddle-agent/src/capture`                                           |
| **Termination**, **decrypt set**                 | The proxy ends TLS, with a leaf certificate from the workspace's CA, for the hosts it must change requests for: hosts with a credential, a secret or a login to capture.                       | `crates/puddle-proxy/src/terminate`; `crates/puddle-ca/src/lib.rs`                                                  |
| **Splice**                                       | Relaying a TLS connection unchanged, without decrypting it; the default for hosts outside the decrypt set.                                                                                     | `crates/puddle-proxy/src/terminate`                                                                                 |
| **Interception mode**                            | Which other HTTPS hosts Puddle decrypts beyond the ones it must: all, all except a curated list, or only the known ones.                                                                       | `crates/puddle-types/src/interception.rs`; `ui/src/lib/interception/modes.ts`                                       |
| **Per-workspace CA**                             | An in-memory certificate authority for one workspace that issues the leaf certificates for termination.                                                                                        | `crates/puddle-ca`                                                                                                  |
| **Never-decrypt list**                           | Host names no workspace, or one workspace, decrypts.                                                                                                                                           | `crates/puddle-services/src/wire/interception.rs`                                                                   |
| **Learned host**                                 | A host where a tool refused Puddle's certificate; Puddle leaves it alone (splices it) for a while.                                                                                             | `crates/puddle-services/src/wire/interception.rs`; `ui/src/lib/components/LearnedHostsList.svelte`                  |
| **Upstream proxy** (company proxy)               | The company's HTTP proxy in front of Puddle, found through PAC, WPAD, policy or environment, with Negotiate, NTLM or Basic sign-in.                                                            | `crates/puddle-upstream`                                                                                            |
| **Hop**, **route** (upstream)                    | An ordered list of ways to reach a destination, each direct or through a proxy, as a PAC file gives them.                                                                                      | `crates/puddle-upstream/src/hop.rs`                                                                                 |
| **Proxy sign-in**                                | A stored user name and password for the company proxy, kept in the OS credential store.                                                                                                        | `crates/puddle-services/src/wire/proxy_sign_in.rs`                                                                  |
| **Corporate roots** (UI: "Company certificates") | The root certificates an admin or the user added on the host, minus the disallowed ones, copied into the guest's CA bundle so TLS inspection works inside.                                     | `CorporateRoots` in `crates/puddle-certs/src/select.rs`                                                             |
| **Network health**                               | The settings page that shows how Puddle reaches the internet: proxy setup, sign-in, company certificates, routes.                                                                              | `crates/puddle-services/src/wire/network_health.rs`; `ui/src/routes/settings/network-health`                        |
| **Port forward**                                 | A guest port made reachable on `127.0.0.1` of the host, carried over the agent's streams.                                                                                                      | `crates/puddle-ports`                                                                                               |
| **Pinned forward** (UI: "Kept")                  | A port forward that comes back at every start.                                                                                                                                                 | `crates/puddle-ports/src/pins.rs`                                                                                   |

## Credentials and identities

| Term                                   | Meaning                                                                                                                                                              | Defined in                                                                                           |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Identity**                           | A git author plus the credentials Puddle adds on the way out, per host and owner or organisation. It holds no secret itself, only where to get one.                  | `crates/puddle-store/src/identity.rs`; `crates/puddle-services/src/wire/identities.rs`               |
| **Commit author**                      | The name and email an identity commits as. Puddle sets it; it never copies the host's `.gitconfig`.                                                                  | `crates/puddle-services/src/wire/identities.rs`                                                      |
| **Credential binding**, **coverage**   | The link from an identity to a credential source, and which owners or organisations on a host it covers. Overlapping coverage in one workspace is refused.           | `crates/puddle-store/src/identity.rs`                                                                |
| **Default identity**                   | The identity a new workspace gets when no other covers its repository.                                                                                               | `is_default` in `crates/puddle-services/src/wire/identities.rs`                                      |
| **Credential source**                  | Where the host reads a secret: a signed-in `gh` account, Git Credential Manager, or a pasted token kept in the OS store. The list is closed.                         | `crates/puddle-types/src/source_spec.rs`; `crates/puddle-secrets`                                    |
| **Injection**                          | On a decrypted git host, the proxy reads the repository and the kind of access, applies the pull and push switches, and adds the covering identity's credential.     | `GitInjector` in `crates/puddle-inject/src/injector.rs`                                              |
| **Pull and push switches**             | Per-repository switches that decide whether a fetch or a push may go out.                                                                                            | `crates/puddle-services/src/wire/identities.rs`                                                      |
| **Repos it can reach**                 | The repositories an identity's credential can list on GitHub or Azure DevOps, cached in memory.                                                                      | `crates/puddle-repos`                                                                                |
| **Stand-in**                           | A fake token with the real one's shape. The workspace holds it; the proxy swaps in the real value only on the way to the right hosts.                                | `StandIns` in `crates/puddle-proxy/src/terminate/stand_in.rs`; `crates/puddle-logins/src/profile.rs` |
| **Captured login** (UI: "Kept logins") | A login made inside a workspace (Claude Code, GitHub) whose real tokens Puddle keeps in the OS store, handing the tool stand-ins. If capture fails, the login fails. | `crates/puddle-logins`; [ADR 0009](../adr/0009-login-capture-fails-closed.md)                        |
| **Capture profile**                    | What Puddle knows about one service's login: its token endpoints, fields and hosts.                                                                                  | `crates/puddle-logins/src/profile.rs`                                                                |
| **Vault**                              | The OS credential-store entries that hold captured tokens, one per workspace and slot; managed with `puddle secrets`.                                                | `crates/puddle-logins/src/vault.rs`; `crates/puddle/src/cmd/secrets.rs`                              |
| **Foreign credential**                 | A credential in a request that Puddle did not add, such as a token the tool brought itself or an old stand-in. Puddle can warn about it.                             | `crates/puddle-types/src/event.rs`                                                                   |
| **Environment variable**, **secret**   | A plain or secret variable, global or per workspace. A secret's value never enters the workspace: it gets a stand-in, swapped only toward the secret's hosts.        | `crates/puddle-services/src/wire/environment.rs`; `crates/puddle-store/src/environment.rs`           |
| **Filtered SSH agent**                 | The SSH agent socket in the guest. Puddle filters it and asks the user before the host's agent signs.                                                                | `crates/puddle-proxy/src/ssh_agent.rs`; `crates/puddle-ssh-agent`                                    |
| **Consent**                            | The user's granted or declined answer, tied to a version of the terms, for software with its own terms such as Microsoft's VS Code server. No answer means no.       | `crates/puddle-settings/src/consent.rs`                                                              |

## Host and app

| Term                                     | Meaning                                                                                                                                                                            | Defined in                                                                                    |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Host**                                 | The host process: one start-up and shutdown sequence that wires the store, proxies, runtime, workspaces, lifecycle and API.                                                        | `crates/puddle-host`                                                                          |
| **Desktop app**, **shell**               | The Tauri window around the single-page app, with the host running in the same process.                                                                                            | `crates/puddle-app`                                                                           |
| **Local API**                            | The HTTP and server-sent-events API the UI and command line use, described by a generated OpenAPI contract.                                                                        | `crates/puddle-api`; [ADR 0004](../adr/0004-api-contract.md)                                  |
| **Event**                                | A host-to-UI notification on the event stream: status changes, new pending requests, a process killed for memory, login problems.                                                  | `crates/puddle-types/src/event.rs`                                                            |
| **Setting**, **override**                | A global setting and its per-workspace override. Each value resolves to the workspace's, the global one or Puddle's default, and the UI shows which.                               | `crates/puddle-settings`; `Source` in `crates/puddle-settings/src/resolve.rs`                 |
| **Editor**, **editor server**            | VS Code in the guest: the open-source server bundled with Puddle, or Microsoft's server after the user accepted its terms; opened in a window or attached from the desktop.        | `ServerChoice` in `crates/puddle-services/src/wire/settings_view.rs`                          |
| **Front**                                | The loopback listener that routes `<workspace>.localhost` (and `<port>.<workspace>.localhost`) to the workspace's editor server or forwarded port.                                 | `crates/puddle-front`                                                                         |
| **SSH endpoint**, **ssh-bridge**         | A per-workspace pipe or socket only the user can open, behind the readiness gate; `puddle ssh-bridge` relays an SSH client's stdio to it as `ProxyCommand`.                        | `crates/puddle-ssh`; `crates/puddle/src/cmd/ssh_bridge.rs`                                    |
| **Direct SSH**                           | A per-workspace switch, off by default, that opens an SSH way in for the user's own tools.                                                                                         | [direct SSH spec](../spec/direct-ssh.md)                                                      |
| **Development certificate**              | Puddle's localhost certificate, so a forwarded server opens in the browser without a warning.                                                                                      | `crates/puddle-certs`; `crates/puddle-services/src/wire/first_run.rs`                         |
| **First run** (UI: "Welcome")            | The setup steps on first start: welcome, system check, certificates, connect, interception, look, done.                                                                            | `crates/puddle-services/src/wire/first_run.rs`; `ui/src/lib/welcome/steps.ts`                 |
| **Doctor**                               | `puddle doctor` and the system check: the host's prerequisites (hypervisor, runtime, test boot, disk, SSH agent, credential store), each finding with its exact fix.               | `crates/puddle-doctor`                                                                        |
| **Data folder**                          | The per-user folder where Puddle keeps its files, with owner-only permissions on the private ones.                                                                                 | `crates/puddle-fs`                                                                            |
| **Backup**, **restore**, **safety copy** | A copy of the database, settings and workspace list (no secrets). A restore first keeps a safety copy of what it replaces.                                                         | `crates/puddle-services/src/backup.rs`; `crates/puddle-services/src/wire/restore.rs`          |
| **Freshness file**                       | A small signed statement, re-signed daily, that protects a future update list against rollback and freeze. No product code reads it yet.                                           | `crates/puddle-freshness`                                                                     |
| **Serve mode**, **users**, **invite**    | `puddle serve`: the host without a window, for browser clients, with an owner, plain users and one-time invite links. Built, but off in the first release (cargo feature `serve`). | `crates/puddle/src/cmd/serve.rs`; `crates/puddle-store/src/users.rs`; [serve.md](../serve.md) |

## Build and test

| Term                   | Meaning                                                                                                                                        | Defined in                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Contract suite**     | The tests every `Runtime` implementation must pass, the fake and msb alike.                                                                    | `crates/puddle-compute`                                         |
| **Fake runtime**       | An in-memory msb with fault injection and a call log, for tests without VMs.                                                                   | `crates/puddle-compute` (feature `fake`)                        |
| **Hostile guest**      | A test that treats everything from the guest as an attack; required for security-relevant changes.                                             | `crates/puddle-e2e`; [STANDARDS.md](../STANDARDS.md), "Testing" |
| **VM tests**           | Tests against real microVMs, with a per-run name prefix and a private `MSB_HOME`.                                                              | `crates/puddle-vm-tests`                                        |
| **UI fixture backend** | The real API on in-memory services, used for UI end-to-end tests.                                                                              | `crates/puddle-e2e`; `crates/puddle-app` (feature `fixture`)    |
| **xtask**              | `cargo xtask runtime`, `code-server` and `openapi`: assemble the bundled msb runtime, unpack the pinned editor server, write the API contract. | `crates/xtask`                                                  |
