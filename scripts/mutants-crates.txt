# The crates mutation testing covers (scripts/mutants.sh, docs/STANDARDS.md "Mutation testing"): one
# per line, comments after '#'. A crate joins this list only when its sweep has no surviving mutant,
# so the list grows as each crate's survivors are fixed with tests.
#
# `crate` lists the whole crate. A crate too big to sweep in one job joins file by file instead: one
# `crate src/file.rs` line per swept-clean file (path under the crate's directory), added as each file's
# sweep is clean, for example
#   puddle-proxy src/route.rs
#   puddle-proxy src/upstream.rs
# A crate uses one form only; when its last file is in, replace its lines with the plain `crate` line.
